Trackers Diarios

Crear tracker diario

Definí un límite unilateral con un tipo (mínimo o máximo). El registro del día se marca como cumplido si alcanza (mín) o no supera (máx) el límite. La desviación muestra cuánto superó el límite (siempre ≥ 0).

El nombre es obligatorio.

El límite debe ser un número.

Registrar valor

El valor debe ser un número.

Editar tracker

Podés cambiar nombre, límite y unidad. El historial de registros no se toca: solo cambia la meta contra la que se evalúan los futuros días.

El nombre es obligatorio.

El límite debe ser un número.
