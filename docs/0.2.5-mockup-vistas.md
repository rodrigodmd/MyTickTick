## Elementos Comunes

### Header
- Logo/Nombre: "MyTickTick"
- Navegación entre vistas (tabs o menú)

### Footer (móvil)
- 📋 Tareas Mensuales
- ⚡ Tareas Inmediatas  
- 📊 Trackers
- 📈 Dashboard (solo desktop)

### Colores
- **Tema**: Vibrant Gradient (dark + moderno) — elegido por el usuario
- **Fondo**: #0a0a0a (primario) / #111111 (tarjetas)
- **Gradientes**: #667eea → #764ba2 (primario) / #f093fb → #f5576c (secundario)
- **Acentos**: púrpura #8b5cf6, rosa #ec4899, azul #3b82f6
- **Alta prioridad**: #e74c3c (rojo)
- **Media prioridad**: #f39c12 (naranja)
- **Baja prioridad**: #27ae60 (verde)
- **Texto**: #ffffff (primario) / #a0a0a0 (secundario)

> ⚠️ El tema claro original (fondo #f5f5f5, tarjetas #ffffff, primario #4a90d9) quedó descartado al elegir Vibrant Gradient.

### Responsive
- **Móvil**: Una columna, menú en footer
- **Desktop**: Columnas opcionales, menú en sidebar o header
