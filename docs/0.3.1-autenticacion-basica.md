# Autenticación Básica en Go

## Enfoque Simple: Usuario/Contraseña

Para la fase de exploración (MVP), usaremos autenticación básica sin complicaciones.

## Flujo de Autenticación

### 1. Registro (Sign Up)
```
Usuario → Formulario → POST /register → Backend → DB
```

**Pasos:**
1. Usuario llena formulario con email y contraseña
2. Backend recibe datos en endpoint `/register`
3. Valida que el email no exista
4. Guarda usuario en base de datos
5. Retorna éxito/error

### 2. Login
```
Usuario → Formulario → POST /login → Backend → DB → Sesión
```

**Pasos:**
1. Usuario llena formulario con email y contraseña
2. Backend recibe datos en endpoint `/login`
3. Busca usuario en base de datos
4. Verifica contraseña
5. Crea sesión (token o cookie)
6. Retorna token de sesión

## Modelo de Datos

```go
type User struct {
    ID        uint      `gorm:"primaryKey"`
    Email     string    `gorm:"uniqueIndex;not null"`
    Password  string    `gorm:"not null"`
    CreatedAt time.Time
    UpdatedAt time.Time
}
```

## Endpoints

### POST /register
**Request:**
```json
{
  "email": "usuario@ejemplo.com",
  "password": "contraseña123"
}
```

**Response (201 Created):**
```json
{
  "message": "Usuario creado exitosamente"
}
```

### POST /login
**Request:**
```json
{
  "email": "usuario@ejemplo.com",
  "password": "contraseña123"
}
```

**Response (200 OK):**
```json
{
  "token": "jwt_token_o_cookie_session",
  "user": {
    "id": 1,
    "email": "usuario@ejemplo.com"
  }
}
```

## Implementación Simplificada

### Sin JWT (para empezar)
- Usar cookie de sesión
- Más simple que JWT para empezar
- No requiere decodificación en cada request

### Con JWT (para futuro)
- Token autocontenido
- Stateless (el backend no necesita guardar estado)
- Más fácil para APIs REST
