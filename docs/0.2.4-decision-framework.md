### React

## Decisión: **Vanilla JS** (por ahora)

### Rationale

1. **Fase de exploración**: Estamos en el MVP, no queremos complicarnos
2. **Simplicidad**: Vanilla JS es más directo y menos "pesado"
3. **Flexibilidad**: Podemos cambiar a React después si necesitamos
4. **Rápido desarrollo**: Menos curva de aprendizaje, más código rápido

### Criterios para cambiar a React

Cambiaríamos a React si:
- El código se vuelve desordenado y difícil de mantener
- Necesitamos componentes más complejos y reutilizables
- El state management se vuelve crítico
- Queremos aprovechar el ecosistema de librerías
